📌 Project Overview

Python Data Visualizer is a beginner-friendly data analysis and visualization project developed using Python and popular data science libraries.

The main purpose of this project is to load a dataset, explore and manipulate data, handle missing values, generate descriptive statistics, and create attractive visualizations.

This project demonstrates the practical use of:

- 🐍 Python
- 🔢 NumPy
- 🐼 Pandas
- 📈 Matplotlib
- 🎨 Seaborn
- 🧱 Object-Oriented Programming (OOP)
- 🧹 Data Cleaning
- 🔍 Data Analysis
- 📊 Data Visualization

---

🎯 Project Objectives

The main objectives of this project are:

- Load and read a CSV dataset
- Explore the structure of the dataset
- Perform DataFrame operations
- Check and handle missing values
- Generate descriptive statistics
- Analyze sales-related data
- Create different types of charts
- Save generated visualizations
- Apply Python OOP concepts
- Build a simple menu-driven data visualization system

---

✨ Key Features

📂 1. Load Dataset

Loads the sales dataset from a CSV file using Pandas.

🔎 2. Explore Data

Allows the user to inspect:

- Dataset records
- Columns
- Data types
- Dataset information

🐼 3. DataFrame Operations

Performs basic Pandas DataFrame operations for manipulating and analyzing data.

Checks the dataset for missing/null values and handles them appropriately.

📊 5. Descriptive Statistics

Generates statistical information such as:

- Count
- Mean
- Standard deviation
- Minimum
- Maximum
- Quartiles

📈 6. Data Visualization

Creates graphical representations of the dataset using Matplotlib and Seaborn.

💾 7. Save Visualization

Generated charts can be saved for future use.

🚪 8. Exit

Provides a simple option to exit the application.

⚙️ Installation

1️⃣ Clone the Repository

git clone <your-github-repository-link>

2️⃣ Open Project Folder

cd Project-9

3️⃣ Install Required Libraries

Or install the libraries manually:

pip install numpy pandas matplotlib seaborn

Run the main Python file:

After running the program, the menu will appear.

Select the required option according to the operation you want to perform.

Example:

Enter your choice: 1

The dataset will be loaded and the selected operation will be performed.
